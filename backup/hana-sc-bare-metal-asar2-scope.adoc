= SnapCenter가 베어메탈 서버와 NetApp ASA 시스템에서 실행되는 SAP HANA 데이터 보호
:hardbreaks:

[role="lead"]
이 문서는 NetApp ASA 시스템에 데이터가 저장되고 X64 베어메탈 서버에서 실행되는 HANA 시스템을 위해 SnapCenter를 사용하는 데이터 보호 모범 사례를 설명합니다.

저자: 닐스 바우어, NetApp



[[scope-of-this-document]]
== 이 문서의 범위

이 문서는 전체 환경을 구성하기 위한 단계별 가이드 역할을 하지 않으며, NetApp ASA 스토리지 시스템에 연결된 베어메탈 서버를 사용하는 SnapCenter 및 HANA에 특화된 세부 정보에 초점을 맞춥니다.

* SAP HANA 시스템 설정
* 특정 SnapCenter 구성
* SnapCenter 백업, 복원 및 복구 작업에 대한 세부 정보
* SnapCenter SAP 시스템 새로 고침 작업 관련 세부 사항


자세한 내용 및 상세한 구성 지침은 해당 link:hana-sc-bare-metal-asar2-additional-info.html["추가 정보"] 장에 나열된 문서를 참조하십시오.

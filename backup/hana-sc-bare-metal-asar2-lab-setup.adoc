아래 그림은 사용된 랩 환경의 개략적인 구성을 보여줍니다. 두 개의 단일 호스트 HANA MDC 시스템을 사용하여 다양한 작업을 시연합니다. HANA 시스템 BM1은 백업, 복원 및 복구 작업을 수행하도록 지정되었으며, HANA 시스템 QM1은 SAP System Refresh 작업의 대상 시스템으로 사용됩니다. HANA 시스템은 두 대의 베어메탈 서버에 배포되었으며, 스토리지 측면에서는 두 개의 ASA A30 2노드 클러스터가 사용됩니다. 첫 번째 클러스터는 HANA 시스템의 모든 스토리지 장치를 호스팅하고, 두 번째 클러스터는 백업 복제의 대상으로 사용됩니다.
